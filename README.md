# ОИК — Бирачки одбор

Десктоп апликација (Windows) за изборне комисије у Србији — општинске, градске
и комисије градских општина. Води цео ток именовања бирачких одбора: фајлове
за странке, обједињавање пристиглих предлога, проверу ЈМБГ-а и сукоба,
корекције, решења за стални и проширени састав, измене решења и посматраче.

## Подршка и одржавање

I-SOFT нуди **подршку и одржавање** за комисије: потписан готов инсталер,
аутоматска ажурирања, усклађивање са изменама закона и РИК образаца пре
сваких избора и помоћ у раду. Програм ради трајно и без интернета — истек
подршке зауставља само ажурирања, никад рад програма.

Контакт: direktor@isoft.rs

кода. Измењене верзије које се даље деле морају да носе другачији назив и не

## За развој

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
python -m biracki_odbor       # покреће програм из изворног кода
pytest                        # тестови
```

Грађење инсталера (редослед је важан):

```powershell
pyinstaller --clean --noconfirm OIK.spec
pyinstaller --clean --noconfirm OIK_Uninstaller.spec
pyinstaller --clean --noconfirm OIK_Setup.spec
```

Програм изграђен из изворног кода ради без лиценцног сервера (`LICENSING_SERVER_URL`
у `biracki_odbor/_build_config.py` је празан).

## Структура

- `biracki_odbor/core/` — пословна логика (фазе, ЈМБГ, корекције, генерисање решења)
- `biracki_odbor/config/` — модели подешавања и изборног циклуса
- `biracki_odbor/validation/` — провере пре и током увоза
- `biracki_odbor/gui/` — PySide6 интерфејс
- `biracki_odbor/integrations/` — мејл клијенти (Outlook, Thunderbird)
- `biracki_odbor/licensing/` — активација и провера лиценце (Ed25519, офлајн)
- `biracki_odbor/installer/` — инсталациони програм
- `biracki_odbor/resources/` — шаблони, закони, упутство (`upustvo.txt`)
- `formalizator/` — Formalizator, програм за попуњавање образаца
- `tests/` — pytest тестови

Измене по верзијама: [CHANGELOG.md](CHANGELOG.md). Библиотеке трећих страна и
њихове лиценце: [NOTICE.md](NOTICE.md).
